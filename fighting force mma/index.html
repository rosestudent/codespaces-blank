About Us

Fighting Force MMA is a martial arts and fitness gym located in Lenasia, Johannesburg, South Africa.

We provide a friendly and supportive environment where beginners and experienced athletes can train, improve their fitness and learn martial arts.

Why Train With Us?

  • Build confidence
  • Improve fitness
  • Learn self-defence
  • Develop discipline
  • Make new friends
  • Prepare for competitions

Our Training Programmes

MMA

Learn striking, grappling, takedowns, ground fighting and MMA fundamentals.

Boxing

Develop punching technique, footwork, defence, speed and conditioning.

Kickboxing

Learn punches, kicks, combinations, movement and fitness.

Self-Defence

Learn practical skills, awareness and confidence to protect yourself.

Kids MMA

A fun and disciplined programme designed to teach children fitness, confidence, respect and basic martial arts skills.

Fitness and Conditioning

Improve strength, endurance, speed and overall fitness.

Technical Requirements

This section explains the technology needed to create and operate the website.

HTML5

HTML5 is used to create the structure and content of the website.

Web Browser

Google Chrome, Microsoft Edge or Mozilla Firefox can be used to view the website.

Computer

A basic computer or laptop is required to create and edit the website.

Code Editor

Visual Studio Code, Notepad++ or another HTML editor can be used.

Internet Connection

An internet connection is needed when publishing the website online and using online features.

Images

Good-quality photographs of the gym, MMA, boxing and training should be used.

Web Hosting

A hosting service is required to make the website available online.

Domain Name

The business would need a suitable domain name, such as a .co.za domain if an appropriate name is available.

Mobile Devices

The website should be tested on smartphones and tablets as well as computers.

Security

When the website is published, HTTPS should be used to help protect visitors and their information.

Backups

Website files should be backed up regularly to prevent loss of information.

Recommended Budget

A realistic starting budget for Fighting Force MMA would be approximately:

R5,000 – R7,000 for the first year.

This would cover a basic website containing:

  • Home page
  • About Us
  • Training programmes
  • Class timetable
  • Membership information
  • Gallery
  • Contact information

After the first year, the main ongoing costs would be domain renewal, hosting and occasional maintenance.

These are estimated costs. Actual prices may vary.
